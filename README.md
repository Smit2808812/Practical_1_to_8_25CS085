## Open and run in VS Code

1. Extract this ZIP file.
2. Open the `Practical_1_to_8_25CS085` folder in VS Code (`File → Open Folder`).
3. Make sure a C++ compiler (such as MinGW-w64 on Windows) is installed and available in PATH.
4. Open the practical `.cpp` file you want to run.
5. Open the VS Code terminal and compile/run it:

```bash
g++ p1_1.cpp -o p1_1
./p1_1
```

On Windows PowerShell, run the compiled program with:

```powershell
g++ p1_1.cpp -o p1_1.exe
.\p1_1.exe
```

Replace `p1_1.cpp` and the output name with the file you want to run.
